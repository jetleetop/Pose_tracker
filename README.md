# AI 실시간 운동 자세 교정 및 카운팅 시스템 (AI Fitness Trainer)

웹캠과 딥러닝을 활용하여 사용자의 바벨 운동(스쿼트, 데드리프트) 자세를 실시간으로 분석하고, 올바른 자세 유지 여부를 판별하여 시각적 피드백과 횟수 카운팅을 제공하는 프로젝트입니다.

---

## 1. 프로젝트 개요

현대사회에서 운동과 건강에 대한 관심은 점점 커져가고 있습니다. 그중에서도 올바른 운동 자세를 유지하는 것은 부상 예방과 운동 효과 향상에 있어 매우 중요한 요소로 자리 잡고 있습니다. 하지만 많은 사람들이 전문가의 도움을 받기 어렵거나, 스스로 자세를 정확하게 파악하기 힘들어 잘못된 자세로 운동을 지속하는 문제가 발생합니다. 특히 스쿼트나 데드리프트와 같은 프리웨이트 운동은 잘못된 자세로 진행할 경우 척추나 무릎 관절에 심각한 부상을 유발할 수 있기에 즉각적인 피드백과 개선이 필요합니다.

기존의 운동 방식은 전문가의 도움을 받거나 거울을 보고 혼자서 자세를 조정하는 식이었습니다. 이러한 방식은 즉각적인 피드백 제공의 한계, 전문가 부재 시 정확도 저하, 비용적·시간적 문제를 가지고 있습니다. 또한 홈트레이닝 사용자가 증가하는 환경에서는 지속적이고 전문적인 지도가 제공되기 어렵습니다.

본 프로젝트는 일반 웹캠 환경에서 MediaPipe를 통해 사용자의 신체 관절 좌표를 추출하고, 딥러닝 모델을 활용하여 사용자가 어떤 운동을 하고 있는지, 올바른 조건으로 운동을 수행하고 있는지를 실시간으로 판별하여 피드백을 주는 시스템입니다.

사용자가 올바른 자세로 운동을 진행할 경우 주요 관절 좌표를 초록색으로 표시하고, 기준을 벗어난 잘못된 자세로 진행할 경우 해당 관절 좌표를 빨간색으로 표시하여 직관적으로 자세를 교정할 수 있도록 돕습니다. 현재 바벨 데드리프트와 바벨 스쿼트 2가지 운동에 대해 실시간 분류 및 자세 판별을 지원하고 있습니다.

---

## 2. 주요 기능

### 1) 운동 종목 자동 분류 및 세부 조건 판별
- 사용자의 관절 좌표를 입력받아 현재 수행 중인 운동(스쿼트, 데드리프트)을 모델이 자동으로 분류합니다.
- 각 운동마다 4~5가지의 운동역학적 세부 조건을 정의하고, 단일 딥러닝 모델에서 이를 동시에 추론하여 정밀하게 평가합니다.
- 세부 판별 조건:
  - **바벨 스쿼트**: 척추의 중립, 고개 정면 유지, 발과 무릎의 방향 일치, 발바닥 지면 고정
  - **바벨 데드리프트**: 척추의 중립, 발과 무릎의 방향 일치, 바벨 궤적과 몸 밀착, 무릎과 골반의 동시 펴짐, 발바닥 지면 고정

### 2) Phase 기반 횟수 카운팅
- 관절 각도 변화를 바탕으로 운동 진행 과정을 3가지 페이즈(Phase 0: 준비 -> Phase 1: 수축/이완 -> Phase 2: 최대 가동범위 -> Phase 0: 복귀)로 나누어 상태를 추적합니다.
- 동작의 전체 사이클(0 -> 1 -> 2 -> 1 -> 0) 동안 모든 세부 조건을 만족한 경우에만 정확한 횟수(Correct)로 카운팅하며, 도중에 자세가 흐트러진 경우 잘못된 횟수(Incorrect)로 구분하여 기록합니다.

### 3) 실시간 피드백 및 대시보드
- 화면 우측에 반투명 대시보드를 배치하여 현재 시스템 FPS, 모델 추론 시간(ms), 운동 종목 분류 확률, 세부 조건별 달성도(%)를 실시간 게이지 형태로 시각화합니다.
- 잘못된 자세가 발생한 관절 부위는 화면상에 빨간색 원으로 강조 표시되어 사용자가 즉각적으로 어느 부위가 잘못되었는지 파악할 수 있습니다.

### 4) 동기부여 요소 및 운동 기록 관리
- 올바른 자세로 연속 성공할 경우 콤보(Combo)가 누적되며, 5콤보마다 추가 보너스 점수가 부여됩니다.
- 누적된 점수에 따라 사용자의 레벨이 계산되며, 가상의 피트니스 상점 아이템을 확인할 수 있습니다.
- 운동을 마치면 전체 기록(일시, 종목, 성공 횟수, 실패 횟수)이 `results.csv`에 자동으로 저장되고, 콘솔에 세션 종합 리포트가 출력됩니다.

## 3. 동작 원리 및 시스템 구조

1. **관절 좌표 추출**: 웹캠에서 입력된 프레임에서 MediaPipe Pose를 통해 24개 주요 신체 관절의 2D 정규화 좌표를 추출합니다.
2. **다중 출력 딥러닝 모델 추론**: 추출된 좌표 벡터를 바탕으로 모델이 운동 종류와 세부 조건별 만족 확률을 동시에 계산합니다.
3. **각도 계산 및 상태 추적**: 무릎 및 고관절(Hinge) 각도를 계산하여 현재 운동의 Phase(0, 1, 2)를 실시간으로 판별합니다.
4. **결과 시각화 및 카운팅**: 상태 전이와 조건 만족 여부를 종합하여 화면에 관절 색상 표시, 대시보드 게이지 업데이트, 횟수 카운팅을 진행합니다.

## 4. 모델 학습 및 데이터 구성

- **학습 데이터**: AI-Hub 피트니스 데이터셋 중 바벨 스쿼트와 바벨 데드리프트 데이터를 활용하였습니다.
- **멀티뷰 데이터 학습**: 정면, 측면, 대각선 등 5개 카메라 앵글(view1 ~ view5)의 관절 좌표 데이터를 모두 학습에 포함시켜 촬영 각도에 따른 인식 안정성을 높였습니다.
- **경량화 (TFLite)**: 원활한 실시간 동작을 위해 Float16 양자화를 적용한 TFLite 모델을 도출하여 저사양 환경에서도 지연 없이 구동되도록 최적화하였습니다.

## 5. 프로젝트 한계 및 개선 방향

본 프로젝트는 웹캠과 MediaPipe, 딥러닝 모델을 활용하여 실시간 운동 자세 분석 및 피드백 시스템을 구현하였으나, 다음과 같은 한계점이 존재하며 추후 개선이 필요합니다.

첫째, 2D 평면 좌표 기반 분석의 한계가 존재합니다. 현재는 2D 화면상의 관절 좌표와 각도를 기준으로 판별하기 때문에, 사용자의 체형이나 카메라와의 각도에 따라 깊이(Z축) 정보의 부재로 인한 각도 오차가 발생할 수 있습니다. 향후 3D 랜드마크 깊이 데이터나 3D 공간 궤적 추적 알고리즘을 도입하여 보완할 수 있습니다.

둘째, 신체 가림(오클루전) 현상에 대한 대응입니다. 바벨 원판이나 헐렁한 옷 등에 의해 무릎, 발목 등의 관절이 일시적으로 가려질 경우 관절 인식이 일시적으로 튀는 현상이 발생할 수 있습니다. 프레임 간 이동 궤적을 보정해주는 필터(예: 칼만 필터)나 시계열 스무딩을 적용하여 안정성을 높일 필요가 있습니다.

셋째, 플랫폼 확장성입니다. 현재는 파이썬 및 OpenCV 기반의 로컬 데스크톱 프로그램으로 동작하지만, 향후 사용자가 별도 설치 없이 웹 브라우저나 모바일 앱 환경에서 쉽게 접근할 수 있도록 이식하는 작업이 요구됩니다.

## 6. 실행 방법

### 환경 설정 및 패키지 설치
```bash
# 가상환경 생성 및 활성화
python -m venv .venv
source .venv/Scripts/activate  # Windows: .venv\Scripts\activate

# 필요 패키지 설치
pip install -r requirements.txt
```

### 프로그램 실행
```bash
# 실시간 운동 자세 측정 프로그램 실행
python new_babel_realtime.py
```
- 프로그램 실행 중 `q` 키를 누르면 종료되며, 해당 세션의 운동 기록이 `results.csv`에 저장되고 최종 리포트가 출력됩니다.

### 모델 학습 및 변환 (필요 시)
```bash
# 모델 학습
python babel_model.py

# 모델 정확도 및 Confusion Matrix 평가
python evaluate_model.py

# TFLite 모델 변환
python convert_tflite.py
```

## 7. 프로젝트 디렉토리 구조

```text
├── aimodel/                               # 학습된 모델 및 TFLite 파일
│   ├── pose_condition_exercise_babel_model.keras  # 메인 Multi-Task 모델
│   └── model_quant.tflite                # Float16 양자화 TFLite 경량화 모델
├── condition/                             # 운동 및 조건 매핑 JSON
│   ├── exercise_index_babel.json          # 운동 인덱스 맵 (스쿼트, 데드리프트)
│   └── exercise_condition_babel_map.json  # 운동별 세부 조건 목록
├── json_files_babel/                      # 학습용 관절 좌표 데이터셋
├── new_babel_realtime.py                  # 실시간 자세 피드백 및 카운팅 메인 프로그램
├── babel_model.py                         # 딥러닝 모델 학습 스크립트
├── evaluate_model.py                      # 모델 평가 및 Confusion Matrix 생성 스크립트
├── convert_tflite.py                      # TFLite 변환 스크립트
├── results.csv                            # 운동 기록 저장 파일
└── requirements.txt                       # 필요 라이브러리 목록
```
